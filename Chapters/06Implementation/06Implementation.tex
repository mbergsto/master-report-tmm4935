\label{ch:implementation}


This chapter describes the implementation of MLguide, a web-based 
decision-support system for machine learning method selection. The 
system combines an ontology-based knowledge graph with semantic 
retrieval from scientific literature to produce ranked method 
recommendations grounded in research literature. It also provides 
starter notebook templates to support the first steps of 
implementation.

The chapter is organised by component. The overall architecture is 
presented first, followed by the knowledge graph and database, the 
recommendation process, notebook generation, the article retrieval 
pipeline, and the web interface. Alongside the description of each component, 
the main design choices are stated together with the reasoning behind them.

\begin{tcolorbox}[colback=gray!5,colframe=gray!60]
The implementation of MLguide is published as open-source and is available at:
\url{https://github.com/mbergsto/MLguide.git}
\end{tcolorbox}
