\chapter{Scopus Search Queries}
\label{app:queries}

Table~\ref{tab:scopus-queries} lists the complete set of Scopus
queries used by the article retrieval pipeline. Each query is
defined in a YAML configuration file with an identifier, a short
description, and a Scopus search string. All queries use the
\texttt{TITLE-ABS-KEY} operator, which matches against article
titles, abstracts, and keywords.
